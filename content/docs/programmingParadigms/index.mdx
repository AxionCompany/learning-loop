## Programação estruturada

A programação estruturada é um paradigma que busca melhorar a legibilidade e a manutenibilidade do código por meio do uso de estruturas de controle bem definidas. O principal objetivo é evitar o uso do comando `goto`, que pode gerar saltos inesperados no fluxo de execução do programa. A programação estruturada organiza o código em blocos lógicos, utilizando as seguintes estruturas de controle: sequência, condição e laços de repetição.

### Características

- **Modularização**: a programação estruturada divide uma aplicação em uma hierarquia de módulos, que podem conter outros módulos.
- **Fluxo de controle estruturado**:  utiliza estruturas de seleção (`if/then/else`), repetição (`while` e `for`) e blocos para controlar o fluxo do programa.
- A programação estruturada evita transferências incondicionais de controle, como as instruções `goto`, que podem dificultar a leitura e a manutenção do código.

### Exemplo — programação estruturada

```typescript
function checkNumber(number: number): void {
  if (number > 0) {
    console.log("O número é positivo.");
  } else {
    console.log("O número não é positivo.");
  }
}

const num: number = parseInt(prompt("Digite um número:") || "0", 10);
checkNumber(num);
```

- **Vantagens do código estruturado:**
  - Fácil de compreender e manter.
  - Utiliza funções para modularizar a lógica.
  - Possui um fluxo de execução previsível.

### Exemplo — programação não estruturada

```c
#include <stdio.h>

int main() {
    int num;

    printf("Digite um número: ");
    scanf("%d", &num);

    if (num > 0) {
        goto positive;
    } else {
        goto negative;
    }

positive:
    printf("O número é positivo.\n");
    goto end;  // Salto desnecessário

negative:
    printf("O número não é positivo.\n");

end:
    return 0;
}
```

- **Problemas do código não estruturado:**
  - O uso de `goto` torna o fluxo de execução mais difícil de acompanhar.
  - O código é mais difícil de compreender e modificar.
  - Pode gerar erros difíceis de identificar e corrigir.

## Programação imperativa

A programação imperativa é um paradigma de desenvolvimento de software que consiste em descrever cada operação necessária para resolver um problema. Ela é caracterizada por uma sintaxe organizada em etapas, que especifica **como** resolver um problema.

### Características

- **Codificação explícita:** cada operação é descrita explicitamente, em vez de utilizar modelos previamente definidos.
- **Sintaxe detalhada:** as linguagens imperativas possuem uma sintaxe detalhada, organizada passo a passo.
- **Alterações de estado:** a programação imperativa enfatiza as mudanças no estado do programa.

### Exemplo — programação imperativa

```javascript
function changeText() {
  const element = document.getElementById("message");
  if (element) {
    element.textContent = "O texto foi alterado!";
    element.style.color = "blue";
    element.style.fontSize = "20px";
  }
}

// Ouvinte de evento para o clique no botão
document.getElementById("changeBtn")?.addEventListener("click", changeText);
```

### Por que isso é programação imperativa?

- **Execução explícita passo a passo:** informamos ao computador exatamente o que fazer em cada etapa.
- **Manipulação direta do estado:** modificamos diretamente o DOM por meio de propriedades como `element.textContent` e `element.style`.
- **Fluxo de controle explícito:** verificamos se o elemento existe antes de manipulá-lo (`if (element)`).

## Programação procedural

A programação procedural é um paradigma que utiliza uma sequência de procedimentos para desenvolver software. Ela é um tipo de programação imperativa.

### Características

- **Modularidade:** divisão de um programa em seções menores e independentes, chamadas módulos. Cada módulo executa uma função específica.
- **Reutilização de código:** os procedimentos podem ser chamados várias vezes sem que seja necessário reescrevê-los.
- **Código mais claro:** dividir um programa em procedimentos facilita a compreensão do código.
- **Facilidade na correção de erros:** isolar tarefas em procedimentos facilita o teste e a depuração de cada parte do programa.
- **Abstração procedural:** permite que os programadores alterem a implementação interna de um procedimento sem precisar informar aos seus usuários.
- **Funções predefinidas:** funções disponíveis em bibliotecas que permitem executar tarefas comuns sem precisar escrever todo o código do zero.
- **Variáveis locais:** variáveis que só podem ser utilizadas no escopo em que foram definidas.
- **Variáveis globais:** variáveis que podem ser acessadas por diferentes métodos e funções do código.
- **Chamadas de função:** controlam o fluxo de execução do código na programação procedural.

### Atenção — desvantagens

- Pode ser excessiva para projetos pequenos.
- Pode apresentar uma curva de aprendizado acentuada para iniciantes.
- Pode levar à engenharia excessiva (*over-engineering*).

### Exemplo — programação procedural

```javascript
// Etapa 1: Separar os ingredientes
function gatherIngredients() {
  console.log("Separando os ingredientes: farinha, açúcar, ovos, leite, manteiga...");
}

// Etapa 2: Preparar a massa
function prepareBatter() {
  console.log("Misturando os ingredientes para preparar a massa...");
}

// Etapa 3: Preaquecer o forno
function preheatOven() {
  console.log("Preaquecendo o forno a 180 °C...");
}

// Etapa 4: Assar o bolo
function bakeCake() {
  console.log("Colocando a massa em uma forma e assando por 30 minutos...");
}

// Etapa 5: Servir o bolo
function serveCake() {
  console.log("Deixando o bolo esfriar e servindo. Aproveite!");
}

// Executa as etapas na ordem correta
function makeCake() {
  gatherIngredients();
  prepareBatter();
  preheatOven();
  bakeCake();
  serveCake();
}

// Inicia o processo de preparo do bolo
makeCake();
```

## Programação funcional

A programação funcional é um paradigma que divide problemas em funções. Trata-se de um estilo declarativo que enfatiza **o que** deve ser resolvido, em vez de **como** resolver o problema.

A programação funcional utiliza expressões e funções sem modificar o estado e os dados existentes. Ao respeitar essas restrições, busca produzir um código mais fácil de compreender e menos suscetível a erros.

### Características

- **Funções de primeira classe**
  - As funções são tratadas como elementos de primeira classe, ou seja, podem ser passadas como argumentos, retornadas por outras funções e atribuídas a variáveis.
- **Funções de ordem superior**
  - São funções que recebem outras funções como argumentos ou retornam funções como resultado.
- **Funções puras**
  - Produzem resultados com base nas entradas recebidas, sem provocar efeitos colaterais e sem depender de alterações externas de estado.
- **Dados imutáveis**
  - As funções recebem entradas e produzem saídas sem modificar os dados originais.
- **Composição de funções**
  - As funções podem ser aplicadas em sequência para resolver problemas complexos a partir de operações menores.

### Exemplo — programação funcional

```javascript
// Lista de produtos
const products = [
  { name: "Notebook", price: 3000 },
  { name: "Mouse", price: 40 },
  { name: "Teclado", price: 100 },
  { name: "Monitor", price: 900 },
];

// 🔹 Etapa 1: Filtrar produtos com preço acima de R$ 50
const expensiveProducts = products.filter((product) => product.price > 50);

// 🔹 Etapa 2: Aplicar um desconto de 10% aos preços
const discountedProducts = expensiveProducts.map((product) => ({
  ...product, // Mantém os demais atributos
  price: product.price * 0.9, // Aplica o desconto de 10%
}));

// 🔹 Etapa 3: Calcular o preço total com desconto
const totalPrice = discountedProducts.reduce(
  (total, product) => total + product.price,
  0
);

console.log("Produtos filtrados:", expensiveProducts);
console.log("Produtos com desconto:", discountedProducts);
console.log("Total final: R$", totalPrice.toFixed(2));
```

### Por que isso é programação funcional?

- **Funções puras:** nenhuma das operações modifica os dados originais da lista de produtos.
- **Imutabilidade:** o método `.map()` cria novos objetos em vez de modificar os existentes.
- **Composição de funções:** `filter → map → reduce` cria um fluxo de transformação de dados.
- **Ausência de efeitos colaterais:** nenhuma das operações altera variáveis externas.

## Programação declarativa

A programação declarativa é um estilo de programação que se concentra no resultado desejado de um programa, em vez de descrever todas as etapas necessárias para alcançá-lo. É um conceito de alto nível frequentemente utilizado em bancos de dados, gerenciamento de configurações e desenvolvimento de interfaces de usuário no front-end.

### Características

- **Definição do resultado desejado:** o programador descreve o que o programa deve fazer, sem especificar detalhadamente como fazê-lo.

- **Determinação das etapas de execução:** o mecanismo responsável pela execução determina as etapas necessárias para alcançar o resultado desejado.

- **Simplicidade:** a programação declarativa pode simplificar o desenvolvimento ao reduzir a necessidade de configurar manualmente cada etapa do processo.
- **Legibilidade:** o código declarativo costuma ser mais fácil de ler do que o código imperativo.
- **Previsibilidade:** o código declarativo pode apresentar um comportamento mais previsível do que o código imperativo.
- **Escalabilidade:** a programação declarativa pode facilitar a escalabilidade em determinados contextos.

### Exemplo — programação declarativa

**Programação imperativa: manipulação do DOM**

```html
<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Manipulação Imperativa do DOM</title>
  </head>
  <body>
    <button id="toggleBtn">Alternar mensagem</button>
    <p id="message" style="display: none;">Olá, mundo!</p>

    <script>
      const button = document.getElementById("toggleBtn");
      const message = document.getElementById("message");

      button.addEventListener("click", () => {
        if (message.style.display === "none") {
          message.style.display = "block"; // Exibe a mensagem
        } else {
          message.style.display = "none"; // Oculta a mensagem
        }
      });
    </script>
  </body>
</html>
```

**Programação declarativa: manipulação do DOM com React**

```jsx
import { useState } from "react";

function App() {
  const [isVisible, setIsVisible] = useState(false);

  return (
    <div>
      <button onClick={() => setIsVisible(!isVisible)}>
        Alternar mensagem
      </button>
      {isVisible && <p>Olá, mundo!</p>}
    </div>
  );
}

export default App;
```

## Programação orientada a objetos

A programação orientada a objetos (POO) é um modelo de programação que organiza o software em torno de objetos, em vez de organizá-lo exclusivamente em torno de funções e lógica. Os objetos representam entidades que combinam dados, atributos e comportamentos.

### Características

- **Como funciona**
  - **Modelagem de dados:** identificar os objetos que serão manipulados e como eles se relacionam entre si.
  - **Criação de classes:** criar definições abstratas para os tipos de objetos que existirão no sistema.
  - **Criação de objetos:** instanciar objetos a partir das classes, que definem suas propriedades e seus comportamentos.
  - **Interação entre objetos:** estruturar programas por meio de objetos que interagem entre si.

- **Benefícios**
  - **Reutilização de código:** definir classes com funcionalidades comuns e reutilizá-las por meio de mecanismos como a herança.
  - **Escalabilidade:** a POO é adequada para sistemas grandes, complexos e que passam por atualizações frequentes.
  - **Eficiência:** a POO pode evitar a duplicação de dados e comportamentos.
  - **Desenvolvimento colaborativo:** a POO pode beneficiar projetos divididos entre diferentes equipes.

### POO — pilares

- **Encapsulamento:** oculta os detalhes internos de um objeto e expõe apenas as partes necessárias.
- **Herança:** permite que uma classe herde atributos e métodos de outra classe.
- **Abstração:** define interfaces ou classes abstratas para ocultar detalhes de implementação e expor apenas o necessário. Também pode ajudar a evitar o acoplamento.
- **Polimorfismo:** permite que um mesmo método tenha diferentes implementações, dependendo do contexto.

### Exemplos — programação orientada a objetos

**Encapsulamento:** oculta os detalhes internos de um objeto e expõe apenas as partes necessárias.

```typescript
class Car {
  private speed: number = 0; // Privado: não pode ser acessado externamente

  accelerate(amount: number) {
    this.speed += amount;
  }

  getSpeed(): number {
    return this.speed;
  }
}

const myCar = new Car();
myCar.accelerate(50);
console.log(myCar.getSpeed()); // 50
```

**Herança:** permite que uma classe herde atributos e métodos de outra classe.

```typescript
class Animal {
  constructor(public name: string) {}

  makeSound(): void {
    console.log("Um som genérico...");
  }
}

class Dog extends Animal {
  makeSound(): void {
    console.log("Au! Au!");
  }
}

const myDog = new Dog("Rex");
myDog.makeSound(); // Au! Au!
```

**Abstração:** define interfaces ou classes abstratas para ocultar detalhes de implementação e expor apenas o necessário, ajudando também a evitar o acoplamento.

```typescript
interface Shape {
  getArea(): number;
}

class Circle implements Shape {
  constructor(private radius: number) {}

  getArea(): number {
    return Math.PI * this.radius ** 2;
  }
}

const circle = new Circle(5);
console.log(circle.getArea());
```

**Polimorfismo:** permite que um mesmo método tenha diferentes implementações, dependendo do contexto.

```typescript
// Classe abstrata que define um método genérico de pagamento
abstract class Payment {
  constructor(protected amount: number) {}

  // Método que será sobrescrito pelas subclasses
  abstract processPayment(): void;
}

// Método de pagamento por cartão de crédito
class CreditCardPayment extends Payment {
  processPayment(): void {
    console.log(`Processando pagamento de ${this.amount} por cartão de crédito`);
  }
}

// Método de pagamento pelo PayPal
class PayPalPayment extends Payment {
  processPayment(): void {
    console.log(`Processando pagamento de ${this.amount} pelo PayPal`);
  }
}

// Função que processa qualquer tipo de pagamento
function makePayment(payment: Payment) {
  payment.processPayment();
}

// Utilização
const creditCard = new CreditCardPayment(100);
const paypal = new PayPalPayment(200);

makePayment(creditCard); // Processando pagamento de 100 por cartão de crédito
makePayment(paypal);     // Processando pagamento de 200 pelo PayPal
```
